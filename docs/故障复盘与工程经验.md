# 本次对话经验教训（2026-09-10～11）

> 背景：115 存储抖动引发增量扫描 EOF 回退风暴、FileMove 全败、实时推送不通，叠加四个 pre 发布与两个正式版。按“故障—根因—修复—教训”记录。

## 一、故障复盘

### 1. 增量扫描 EOF 回退风暴
- 现象：`增量遍历失败: EOF → 回退全量 → 全量同样 EOF`，请求量翻倍。
- 根因：单目录失败中断整树 + 无条件回退全量（R1）。
- 修复：子目录失败跳过并带路径上报，仅根失败返回；不完整时沿用旧快照、不清理、不回退。

### 2. FileMove 批量 EOF（20:33 全败）
- 现象：12 个文件 `move …: EOF`，手动脚本却能搬。
- 根因三叠加：
  1. **探测误判**：`FSGet(目标)` 遇驱动抖动返回 EOF，代码把任何错误当“不存在”放行，盲 move；
  2. **缓存影子**：`refresh=false` 列表过期，源早被外部搬走还在扫，属正常“源消失”却按失败重试；
  3. **10s 掐线**：客户端全局超时 10s，而 115 冷 `mkdir` 实测 ~10s、GB 级 move 更久——客户端掐线、服务端随后做完，“报 EOF、文件却在目标里”。
- 修复：探测三段论（存在/不存在/未知，未知停手）；源消失记跳过；`move` 歧义失败验靶（目标存在+大小一致计成功）；写操作 300s 超长通道，读保持 10s。

### 3. 实时推送恒 500
- 现象：按钮点不动（静默失败），直连 curl 握手 500。
- 根因：`requestLogger` 的包装 writer 未实现 `http.Hijacker`，gorilla 无法升级——该功能**从上线起就没通**过。
- 教训：静默失败比报错更贵；此前若有一条握手回归测试，早就暴露。

### 4. `/api/fs/copy` 同步/异步误判
- 走弯路：先是“只等状态码”（错），又加任务轮询（对方向、超配实现），最后落地。
- 证据：Alist 服务端 GIN 日志 `POST /api/fs/copy → 200` 仅百微秒，真活在后台 `copy` 任务；同盘 1.4GB 6 秒回包是快路径特例。
- 落点：完成只看目标状态（存在+大小一致）；任务列表（`GET copy/undone|done`，注意是 GET，POST 会落进 SPA 回 HTML）只做绑定与进度观测。

## 二、工程教训

1. **错误三段论**：存在 / 不存在 / 未知。未知（EOF/限流/超时）绝不按任一确定分支放行——放行就是把一次抖动变成数据错误。
2. **报错≠没做**：超时/掐线/异步提交后，必须验终局（目标校验）再定性；宁可“未知留待下轮”，不误判成功（误判成功=丢数据），也不误判失败（误判失败=重试风暴）。
3. **超时是传输护栏，不是业务裁决**：超时只决定“不等了”，完成与否看服务端状态；轮询退出看状态（终态/丢失计数/ctx），不看墙钟。
4. **失败清残留**：`never`（存在即跳）/`if_newer`（残留 mtime 更新）下，一次失败的半截文件会永久卡死该文件——终态失败必须尽力清目标。
5. **快照只增量语义**：采集可以全量，但失败路径绝不污染快照（失败 FSGet 剔除、异常子树沿用旧条目），否则“失败固化、永不重试”。
6. **共享客户端取最小**：同服多任务共享限流器必须取最小（防带 burst）；读写分离超时（读快失败、写超长）。
7. **中间件别吞能力**：包装 `ResponseWriter` 必须透传 `Hijacker`（及 `Flusher`），否则 WS/SSE 全灭——且要有握手级回归测试。
8. **日志级别是语义**：探测类“不存在”是正常预期，进 Debug；级别过滤按行匹配，错误消息必须单行（`errors.Join` 换行会拆散过滤与展示）。
9. **先实测再下结论**：6s copy、9.8s mkdir、1208 项分页、`undone/done` 可用性，全部是 curl 出来的；拍脑袋的 300s 要如实标注“保守上限、待耗时分布收紧”。
10. **测试对齐生产**：单测直连 sqlite 必须补 `busy_timeout` + 单连接，否则 CI 偶发 `SQLITE_BUSY`（cover 模式下必现得更勤）；CI 挂先看是不是 flake，用 `-count` 本地复现再定责。
11. **发布纪律**：分支→PR→CI 绿→合→tag→流水线→手写 release notes（流水线 auto-notes 只含增量）；pre 线性累积，正式版 notes 按 PR 实际内容写，不贴 merge 提交。

# 并发压测指南

## 运行单元测试

```bash
# 运行所有测试
go test -v ./...

# 运行特定包的测试
go test -v ./internal/storage/...
go test -v ./pkg/alist/...

# 运行竞态检测
go test -race ./internal/storage/...
go test -race ./pkg/alist/...
```

## 并发压测场景

### 1. GlobalStore 竞态测试
**文件**: `internal/storage/store_race_test.go`

测试场景：
- 50 个 goroutine 同时调用 `SetGlobalStore` 和 `GlobalStore`
- 每个 goroutine 执行 100 次操作
- 使用 `-race` 标志检测数据竞争

```bash
go test -race -v -count=5 ./internal/storage/ -run TestGlobalStoreRace
go test -race -v -count=5 ./internal/storage/ -run TestConcurrentSetGlobalStore
```

### 2. AlistClient GetClient 竞态测试
**文件**: `pkg/alist/client_race_test.go`

测试场景：
- 50 个 goroutine 同时调用 `GetClient` 获取相同客户端
- 每个 goroutine 执行 50 次获取操作
- 验证只有一个客户端实例被创建

```bash
go test -race -v -count=5 ./pkg/alist/ -run TestGetClientRace
go test -v -count=5 ./pkg/alist/ -run TestGetClientDuplicateCreation
```

### 3. SaveSnapshot 数据完整性测试
**文件**: `internal/storage/store_snapshot_test.go`

测试场景：
- 测试并发更新快照不会导致数据丢失
- 测试部分更新不会丢失旧数据

```bash
go test -race -v ./internal/storage/ -run TestSaveSnapshot
```

## 完整压测命令

```bash
# 安装 sqlite3 开发依赖（如果需要）
# Ubuntu/Debian: sudo apt-get install libsqlite3-dev
# macOS: brew install sqlite3

# 运行所有测试（带竞态检测）
go test -race -v ./...

# 运行测试并生成覆盖率报告
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out -o coverage.html

# 压测 100 轮
go test -race -count=100 ./internal/storage/...
go test -race -count=100 ./pkg/alist/...
```

## 预期结果

### GlobalStore 竞态测试
- 无 data race 检测
- 所有 goroutine 能正确获取到设置的 Store

### GetClient 竞态测试
- 只会创建一个客户端实例
- 无重复创建

### SaveSnapshot 测试
- 并发更新不会导致数据丢失
- 快照数据完整
